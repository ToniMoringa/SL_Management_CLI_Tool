INSTALLATION INSTRUCTIONS

➤ Step 1: Clone the repository
git clone https://github.com/ToniMoringa/SL_Management_CLI_Tool
cd SL_Management_CLI_Tool

➤ Step 2: Create virtual environment
python3 -m venv venv
source venv/bin/activate

➤ Step 3: Install dependencies
pip install rich

➤ Step 4: Run the tool
python3 project_cli.py help

QUICK START

$ python3 project_cli.py add-user "Manon" --email alice@example.com
$ python3 project_cli.py add-project "Manon" "E-Commerce Website"
$ python3 project_cli.py add-task "Manon" "E-Commerce Website" "Design Database" --assignee Manon
$ python3 project_cli.py done "Manon" "E-Commerce Website" "Design Database"
$ python3 project_cli.py dashboard

COMMAND REFERENCE

User Management

Command Description Example
add-user NAME --email EMAIL Create new user add-user "Asha" --email Asha@work.com
set-email USER EMAIL Update user email set-email "Asha" new@email.com
list-users Show all users list-users

Project Management

Command Description Example
add-project USER TITLE Add project to user add-project "Asha" "Website Redesign"
list-projects USER Show user's projects list-projects "Asha"

Task Management

Command Description Example
add-task USER PROJECT TASK --assignee NAME Add task to project add-task "Asha" "Website" "Design" --assignee Asha
list-tasks USER PROJECT Show tasks in project list-tasks "Asha" "Website"
done USER PROJECT TASK Mark task complete done "Asha" "Website" "Design"
reassign USER PROJECT TASK NEW_ASSIGNEE Reassign task reassign "Asha" "Website" "Design" "Malik"

Views

Command Description Example
dashboard Show global progress dashboard
dashboard USER Show user progress dashboard "Asha"
search KEYWORD Search all data search "database"
help Display command reference help

COMPLETE WORKFLOW EXAMPLE

𖤓 Complete Team Sprint Setup
1. Create your team
python3 project_cli.py add-user "Namjoon" --email Namjoon@example.com
python3 project_cli.py add-user "Asha" --email Asha@example.com
python3 project_cli.py add-user "Malik"

2. List your team
python3 project_cli.py list-users

3. Assign projects
python3 project_cli.py add-project "Namjoon" "E-Commerce Website"
python3 project_cli.py add-project "Asha" "API Gateway"
python3 project_cli.py add-project "Malik" "Mobile App"

4. Add tasks with assignees
python3 project_cli.py add-task "Namjoon" "E-Commerce Website" "Design Database" --assignee Alice
python3 project_cli.py add-task "Asha" "API Gateway" "Implement Rate Limiting" --assignee Bob
python3 project_cli.py add-task "Malik" "Mobile App" "Create Login Screen" --assignee Carol

5. Reassign a task
python3 project_cli.py reassign "Namjoon" "E-Commerce Website" "Design Database" "Bob"

6. Complete tasks
python3 project_cli.py done "Asha" "API Gateway" "Implement Rate Limiting"
python3 project_cli.py done "Malik" "Mobile App" "Create Login Screen"

7. View progress
python3 project_cli.py dashboard

8. Search
python3 project_cli.py search "API"

⚙︎ TROUBLESHOOTING

Problem: "python3: command not found"
Solution: Install Python 3.8+ from python.org

Problem: "ModuleNotFoundError: No module named 'rich'"
Solution: Activate venv: source venv/bin/activate then pip install rich

Problem: Data not persisting
Solution: Check write permissions: ls -la projects.json

Problem: Video not playing
Solution: Ensure demo.mp4 is in folder
